User types message → clicks "Analyze"
        ↓
POST /scan  { message, input_scanners: [...], output_scanners: [...], strict_mode: bool }
        ↓
scan_engine.py
  → instantiate selected input scanners with their configs
  → run scan_prompt(message, scanners)
  → collect per-scanner: is_valid, risk_score, sanitized_text
  → (output scanners run on sanitized_text as if it were LLM output)
        ↓
Response JSON → right panel renders full report
              → chat bubble gets 🟢/🟡/🔴 status badge
